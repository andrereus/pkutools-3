# BLS name translation glossary (de → es, fr)

Reference for the Spanish and French BLS food names in `bls-names-i18n.json`.
BLS names are built as `base food, qualifier, qualifier`; the qualifiers repeat
across thousands of entries, so they are translated the same way everywhere.
Adjectives agree with the head noun (`Kartoffel, gekocht` → `Patata, cocida` /
`Pomme de terre, cuite`), so the forms below are listed in the masculine and
inflected as needed.

Numbers keep the German decimal comma (`3,5 % Fett`), which is also the
Spanish and French convention.
